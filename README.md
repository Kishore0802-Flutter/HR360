# HR#360 Flutter client

See `../README.md` for the complete setup. Android, iOS and optional web platform scaffolding are included. Before running: `flutter pub get`, then `dart run tool/setup.dart` if you need to refresh permissions/scaffolding, and `dart run flutter_launcher_icons` to regenerate branded launcher assets.

Configure API_URL at build/run time. The backend must be reachable by the device. Login uses operator-created accounts; this is not a mock-data demonstration.

Do not commit signing credentials, key.properties, .env files, .dart_tool, build outputs or local.properties.
